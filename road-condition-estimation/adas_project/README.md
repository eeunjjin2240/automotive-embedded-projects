# 도로 상태 추정 시스템 (Road Condition Estimator)

## 📂 파일 구성

```
road_condition/
├── road_condition_estimator.m   # 메인 계산 코드 (1단계)
├── visualize_realtime.m         # 실시간 시각화 (2단계)
├── testset1.mat                 # 입력 데이터 (사용자 보유)
└── road_results.mat             # 1단계 실행 후 자동 생성
```

## 🚀 실행 방법

매트랩에서 다음 순서로 실행하세요.

### 1단계: 데이터 처리 및 도로 상태 계산
```matlab
>> road_condition_estimator
```
- testset1.mat을 읽어 모든 신호를 처리
- 슬립 / RMS / μ / 도로 상태 지수 계산
- `road_results.mat` 파일을 자동 저장

### 2단계: 실시간 시각화 (자동차 주행 시뮬레이션)
```matlab
>> visualize_realtime
```
- road_results.mat을 읽어 4영역 통합 대시보드 표시
- 실시간으로 차량이 도로를 달리며 상태가 갱신
- 재생 속도 조절: `PLAY_SPEED` 변수 (기본 30배속)

## 🔧 시스템 구조 (플로우차트 매핑)

| 플로우차트 블록 | 매트랩 구현 | 사용 변수 |
|---|---|---|
| **타이어 슬립 라인** | | |
| └ 4바퀴 휠속도 + VS | 입력 | WHL_SPD_FL/FR/RL/RR, VS |
| └ 슬립비 계산 (코너링 YAW 보정) | `whl_FL_c = whl_FL + (TREAD/2)·yaw·3.6` | YAW_RATE |
| └ 슬립 지수 산출 | `slip_idx = 0.7·slip_ratio + 0.3·sqrt(var)` | + 1초 이동평균 |
| **IMU Z축 진동 라인** | | |
| └ AccelZ / AngRate | 입력 | AccelZ, AngRateY |
| └ Bandpass filter (0.5~10 Hz) | `butter(4, [0.5 10]/50, 'bandpass')` + filtfilt | |
| └ 진동 RMS 산출 (1초 윈도우) | `sqrt(movmean(accZ_bpf², 100))` + 속도 정규화 | |
| **도로 경사도 라인** | | |
| └ AnglePitch / VelDown | 입력 | AnglePitch, VelDown, VelForward |
| └ 경사도 계산 atan2(VelDown, VelFwd) | `slope = 0.7·pitch + 0.3·atan2(-velDown, velFwd)` | |
| └ 경사 가중치 w_grade = f(\|θ\|) | `w_grade = 1/(1 + (\|slope\|/10)²)` | |
| **마찰계수 μ 추정** | | |
| └ 동적 하중이동 고려 | `μ ≈ \|accX\| / (g·cos(slope))` + 클리핑 | AccelX |
| **도로 상태 지수 산출** | | |
| └ 슬립 + RMS + μ × w_grade | `0.55·rms + 0.30·slip + 0.15·mu_inv` (백분위수 정규화) | |
| └ 경사 보정 | `idx · w_grade + (1-w_grade)·rms_only` | |
| **임계값 판단** | | |
| └ TH1 / TH2 | **적응형** (60% / 90% 분위수) | |
| └ 좋음 / 양호 / 나쁨 | grade = 1 / 2 / 3 | |

## 💡 핵심 아이디어

### 1. 백분위수 기반 정규화
이 프로젝트에서는 슬립이나 진동의 절댓값을 임의의 임계값으로 비교하지 않습니다.
대신 **이번 주행 데이터의 분포에서 95% 분위수**를 1.0의 기준으로 삼아 정규화합니다.
→ 어떤 데이터를 넣어도 자동으로 스케일이 맞춰집니다.

### 2. 적응형 임계값
TH1/TH2도 데이터 분포 기반(60%, 90% 분위수)으로 결정됩니다.
→ 결과: 좋음 60% / 양호 30% / 나쁨 10% 분포로 의미 있는 시각화 보장

### 3. 경사 보정
경사로에서는 슬립이 자연스럽게 발생하므로, 경사가 클수록 슬립/μ의 영향을 줄이고
순수한 진동 RMS만으로 노면을 평가합니다.

```
road_index = w_grade · (RMS+slip+μ) + (1-w_grade) · RMS
```

## ⚙️ 주요 파라미터 (조정 가능)

| 파라미터 | 기본값 | 설명 |

| BPF 대역 | 0.5 ~ 10 Hz | 노면 진동 대역 |
| `DS` | 10 | 다운샘플링 비율 (100Hz → 10Hz) |
| `PLAY_SPEED` | 30x | 시각화 재생 속도 |

## ✅ 결과물

실행하면 다음을 확인할 수 있습니다.
- 약 40분간의 주행에서 도로 상태가 시간순으로 갱신
- GPS 경로 (수원~서울 강남 약 30km) 위에 등급별 색상 표시
- 차량의 실시간 이동과 함께 좌측 상단에 현재 등급 게이지

이 시스템은 **확실한 노면 종류 단정**보다는 **상대적 도로 품질 등급화**를 목표로 합니다.
즉, "이 도로의 상태가 다른 구간 대비 얼마나 좋은가/나쁜가"를 평가합니다.
